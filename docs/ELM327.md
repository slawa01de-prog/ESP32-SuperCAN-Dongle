# ELM327 compatibility work

ELM327 emulation is a separate experimental workstream and is **not enabled in the passive default sniffer firmware**.

A convincing ELM-compatible endpoint requires more than returning an `ELM327` banner. Diagnostic applications can depend on:

- AT command behavior
- command echo settings
- spaces and line endings
- prompt timing
- header configuration
- protocol selection
- filtering
- ISO-TP behavior
- response timing and timeouts

Compatibility with tools such as DDT4All is therefore considered **work in progress** rather than a finished feature.

Future work should keep the ELM layer separate from the passive sniffer core so that CAN capture remains simple and reliable.
