# Renault ZOE research example

This folder documents the origin of some of the development work. Early testing was performed while investigating Renault ZOE CAN traffic.

The public repository keeps the main firmware vehicle-agnostic and passive. Vehicle-specific active diagnostic/write commands are intentionally not included in the default public firmware.

Planned safe additions for this example:

- observed CAN-ID catalog
- capture annotations
- verified passive signal decoding
- screenshots of decoded dashboards
- notes comparing captures under different vehicle states

All definitions should be marked as **verified**, **inferred**, or **unknown**.
